# Agent 浏览器界面

## 背景与目标
CcCode 当前以终端界面展示 Agent 交互；用户希望通过浏览器使用以对话为中心的界面，并查看工具执行过程。

## 能力
- 在本机浏览器展示对话、流式回复及可展开的工具调用和结果。
- 提供输入、停止、权限确认和 Agent 提问交互。
- 展示当前模型、工作目录、权限模式、连接和运行状态。
- 复用现有 Agent、工具、权限、会话和扩展系统。
- 保留终端入口供现有用户使用。

## 非功能要求
- 仅监听本机，避免将具有本机操作能力的 Agent 暴露到网络。
- 浏览器断开时中断正在运行的任务，避免权限请求悬挂。
- 界面适配常见桌面和移动窗口尺寸，支持键盘操作。

## 设计骨架
浏览器通过本地服务连接 Agent；服务把结构化事件传递给界面，并将用户输入与权限选择交还 Agent。

## 不在本次范围
远程访问、多用户账号、云托管、编辑器功能及新的模型供应商。
